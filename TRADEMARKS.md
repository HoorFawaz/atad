# ATAD name and logo policy

"ATAD", "عَتاد" and the ATAD logo identify the official project by
the ATAD Team (Hoor Fawaz and Danah Fawaz). This policy explains how you may use them. It is separate
from the software license: the license covers the code, this policy
covers the name.

## Allowed without asking

- Saying truthfully that your work is "based on ATAD" or "works with ATAD".
- Naming an **unmodified** official release "ATAD" when you redistribute it for free.
- Writing about ATAD in articles, research, courses, talks and reviews.
- Linking to the official project: https://github.com/HoorFawaz/atad

## Needs written permission

- Using "ATAD", "عَتاد", or a confusingly similar name for a **modified** version
  (modified versions must use a different name — see Section 4(e) of the license).
- Using the ATAD logo in a product, website, service or advertisement.
- Calling a product, service, training or support offer "official", "certified"
  or "endorsed" by ATAD.
- Using the name in a company, product or domain name.

## Why this matters

ATAD is a security tool. A modified copy that carries the official name
could hide malicious changes and harm its users. Keeping the name for
official releases lets users trust what they download, together with the
SHA-256 hashes published with every release.
